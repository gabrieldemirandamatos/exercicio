# Exercícios de Lógica e Algoritmos em Python

Este repositório foi criado para organizar e registrar minha evolução nos estudos de programação usando Python. Aqui guardo os códigos e exercícios práticos de lógica e estrutura de dados que venho desenvolvendo.

---

## O que tem aqui até agora

### 1. execicio1.py
Neste arquivo, resolvi dois desafios práticos:

* **Pesquisa Binária:** Uma forma rápida e eficiente de procurar um item dentro de uma lista organizada. Em vez de olhar item por item, o algoritmo vai dividindo a lista pela metade até encontrar o valor desejado (no caso, um ID associado a um nome).
* **Contagem de Números Primos:** Uma função simples que percorre uma lista de números primos e conta quantos deles são menores do que um número específico.

## Como rodar o código na sua máquina

1. Instale o Python no seu computador, se ainda não tiver.
2. Baixe o arquivo execicio1.py ou clone o repositório.
3. Abra o terminal na pasta onde o arquivo está salvo.
4. Execute o comando:

python execicio1.py
